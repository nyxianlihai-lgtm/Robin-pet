# Robin-pet v1.0

Windows 知更鸟同人 AI 桌宠，使用 PySide6，支持透明视频动作、桌面互动、DeepSeek 兼容接口聊天及 Windows 本地语音。

上传 GitHub 的步骤见 [GITHUB_UPLOAD.md](GITHUB_UPLOAD.md)。建议仓库名 `Robin-pet`，版本标签 `v1.0`。

当前采用“参考视频2”中的 **学院换装**形象，独立于 `E:\DSH\DSH-pet` 运行。原项目未修改，也不读取它的账号、配置或聊天记录。原 A 礼服形象与第一批视频素材保留。

## 运行

本机已安装独立环境，双击 `启动桌宠.bat` 即可启动。首次运行会同时打开陪伴面板。

换一台 Windows 电脑时，需要安装带有 pip 的 Python 3.10 或更高版本，再运行 `setup.bat` 安装依赖。

## 使用

- 默认播放你提供的视频：自然眨眼和轻微姿态变化。
- 单击角色显示摸头反馈与气泡，并立即播放抬手招呼；暂无专门的摸头或入睡视频。
- 拖动角色：移动位置；双击：打开聊天面板。
- 右键角色：待机、抬手招呼、转身再回来、向左散步、暂停/继续、置顶、回到右下角、隐藏、退出。
- 托盘图标：双击打开面板，右键显示控制菜单。
- 关闭面板只会隐藏面板；退出请用角色或托盘的“退出桌宠”。
- 设置中可以调整角色高度、散步、置顶和自动朗读。

## 接入 DeepSeek

在“模型与设置”中填入 API Key，保存，再回到“聊聊天”发送消息。默认接口为 `https://api.deepseek.com`，模型为 `deepseek-flash`；模型名可以自定义，也支持兼容接口和本机模型。

默认模型参考 2026-10-27 的 [DeepSeek 官方接入文档](https://api-docs.deepseek.com/)。模型可用性以服务商实际返回为准。使用自己的 Key 可能产生服务商 API 费用。没有 Key 仍可使用所有本地桌宠互动，界面不会将本地台词冒充为 AI 回复。

聊天上下文最多保留最近 10 轮，退出后清空。请求可取消，超时和认证错误会在面板显示；失败消息放回输入框。

## 本地数据与语音

- 设置保存在 `data/settings.json`。API Key 用 Windows DPAPI 加密，绑定当前 Windows 用户，无法直接复制给其他账号使用。
- 对话文本仅保留在内存；发送聊天时会将最近对话和角色设定发给你配置的服务商。
- 语音调用 Windows 本地语音合成，不上传声音。安装中文系统语音可获得中文朗读；这是系统声音，并非游戏角色原声。不含麦克风识别功能。
- 启动错误记录在 `data/startup-error.log`，运行错误记录在 `data/error.log`。

## 当前动画范围

当前版本使用 `参考视频2/` 的四段 1280×720、24fps 视频，每段 121 帧，约 5 秒。离线抠出中央角色，保留封闭虹膜颜色，输出 580×700 无损透明 PNG，保留源像素尺度。每段使用固定缩放和落脚锚点；走路片另用头部模板跟踪去掉源视频内的水平漂移，不按每帧外接框裁切或缩放。

待机取抬手视频的前 45 帧并往返循环，约 3.67 秒，保留自然眨眼。手动选择动作立即响应，可以替换正在播放的动作；切换用约 0.12 秒的整帧淡化过渡，不做肢体拼接或光流。抬手从第 44 帧进入，跳过视频开头近两秒的静止；手动转身从第 20 帧进入。动作完成后回到待机循环，点击“待机视频”也能立即恢复。双手放下视频的起始手势与单手抬起视频不一致，保留存档，不强行拼接。

散步流程为：正面转左侧 → 正向走路循环两遍 → 停下并倒放转回正面。程序只在实际迈步片段中移动窗口，280px 角色的速度约 28px/s。开启自动散步后，首次约 22 秒后排队，之后每次结束间隔 22–38 秒；默认仍关闭自动散步。仅支持向左，接近左边界后停止自动发起；可拖动或回到右下角。没有镜像饰品来冒充向右行走。

同段往返的接点相邻；跨视频的正面/侧面姿势不是同一原帧，仍有轻微差异。走路循环选取相近脚步相位，无法修复源视频本身的线条变化或保证完全无滑步。暂无向右行走、独立背面转正面、摸头、入睡或语音口型素材。没有光流、生成补帧或手臂拼接。暂停和拖动会保持当前帧，恢复后继续。

当前素材在 `assets/video2_hq/`：保留原视频的像素尺度，统一固定裁去空白画布后存为 580×700 无损透明 PNG，共 484 帧。没有先缩小一半。`manifest.json` 记录动作顺序、锚点、源文件校验值、固定变换及走路跟踪位移。显示缓存按屏幕实际 DPI 生成，跨屏时刷新缓存。眼睛只保护靠近肤色且有亮色的小型封闭虹膜区域，不再用固定椭圆把背景也填实。`assets/video2/` 保留之前的低分辨率版本，`assets/video_idle/` 保留第一批礼服素材。

旧帧图、光流和关节动画保留作归档，不进入默认播放路径。`tools/prepare_video2.py` 是本批离线抠像与归一化脚本，制作工具需要 OpenCV/NumPy；桌宠运行不需要。

双击 `动作预览.bat` 独立查看浅色/深色背景，不影响已有桌宠聊天。按 1 待机、2 抬手招呼、3 转身、4 散步，空格暂停，方向键逐帧。独立预览检查透明边缘，散步在预览中原地播放；桌宠窗口会随迈步移动。更新后，已运行的旧版需要从托盘退出再启动。

这是个人同人项目，不是游戏官方应用。

## 验证

运行 `.venv\Scripts\python.exe verify.py` 可执行离屏界面检查、本地模拟 API 测试和加密往返测试，并输出 `qa/panel.png` 与 `qa/pet.png` 供检查。测试不连接真实模型服务。

运行 `.venv\Scripts\python.exe verify_motion.py`（或 `verify_video.py`）可检查四段源文件未改动、484 帧完整性、透明背景、眼睛保护、原帧往返接点、立即互动与动作替换、恢复待机循环、暂停/拖动冻结及仅在走路时产生位移。

运行 `E:\python\python.exe tools/verify_video2_matte.py` 可逐帧对照源视频，检查明确的外部绿幕像素是否透明，以及画布边缘是否裁到角色。`verify.py` 也已在 `QT_SCALE_FACTOR=2`（200% 缩放）下通过。

`verify_tween.py`、`verify_rig.py` 与 `verify_motion_legacy.py` 属于旧方案的检查，保留作归档，不代表默认播放效果。

修复后的演示视频为 `qa/video2-hq/动作预览.mp4`，同时展示待机、招呼、转身、散步的实际播放器序列。制作脚本 `tools/render_video2_preview.py`；浅/深背景检查图片也在 `qa/video2-hq/`。原视频及平台标识保留在原文件中，处理结果只提取中央角色；来源记录见 `assets/video2_hq/素材说明.md`。
